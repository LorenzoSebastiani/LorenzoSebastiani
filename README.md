## 💼 Esperienza — Tirocinio @ Logicos

- **Suite gestionale full-stack** (NestJS + React/Ant Design + PostgreSQL): sviluppo di moduli backend e componenti frontend, code review, risoluzione di problemi di dependency injection, gestione di relazioni many-to-many, editor JSON chiave-valore dinamici.
- **Sistema di monitoraggio applicativi**: servizio Node.js/Express che esegue test UI (Puppeteer) e API (Axios) programmati, salva lo storico su SQLite e invia report via Telegram. Containerizzato con Docker.
- **API proxy per Borg Backup**: servizio Express/TypeScript che espone via HTTP gli script di backup, con storico delle esecuzioni.
- **Integrazione di log di sicurezza**: backend NestJS collegato a ArcSight ed Elasticsearch/Suricata, con interfaccia di ricerca per analisti (filtri, paginazione).
- **Editor di planimetrie DWG**: sistema di messaggistica real-time generico (thread polimorfici, stato di lettura, permessi basati su ruoli) con WebSocket e Zustand.
- **DevOps**: deploy e manutenzione su server Linux, Docker, gestione permessi e script di aggiornamento.
